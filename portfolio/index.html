Case file 002 APT36 / Transparent Tribe — credential harvesting

The Wrong Tenant

A five-node, three-provider cluster, active 22 months, with no prior public reporting found on it. Traced out from a single already-published C2 using ASN and certificate-infrastructure pivoting alone — no privileged telemetry, no vendor feed.

The cluster deliberately impersonated a real Mexican manufacturer, and carried a Clarivate / CompuMark brand asset, to make the phishing infrastructure look legitimate to Spanish-speaking targets.

Method — pinned where it can be seen

How I keep myself honest

  • Every claim gets a label. Confirmed, high confidence, or working hypothesis. If I can’t label it, it doesn’t go in.
  • Infrastructure is not attribution. Two hosts sharing a certificate is a fact about certificates. The writeup says plainly which of the two I’m claiming, every time.
  • ATT&CK only gets what I watched happen — never what the family usually does.
